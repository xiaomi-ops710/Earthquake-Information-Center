# 地震・津波速報 PWA

P2P地震情報 API（REST `/history` + WebSocket）を使うリアルタイム地震・津波速報。Material 3 Expressive をベースにした NERV 風ダークUI（iPad 3カラム対応）、Leaflet 地図、localStorage キャッシュ、FCM プッシュ対応。

## 構成
- `js/geo.js` … 都道府県・距離・現在地判定・P2P地域コード表の取得（感知の地点表示に使用）
- `js/stats.js` … 統計画面の描画
- `index.html / css/app.css / js/app.js` … アプリ本体（ビルド不要）
- `sw.js` … オフラインキャッシュ + FCM バックグラウンド通知
- `config.js` … Firebase / 中継サーバーURL の設定
- `relay/` … P2P WebSocket → FCM 即時送信サーバー（Node 18+）。`server.js` / `logic.js` / `volcano.js` / `package.json` を**そろえて**デプロイ

## 1. GitHub Pages で公開
このフォルダの中身（`relay/` は除いても可）をリポジトリ直下に置き、Settings → Pages で `main` / root を公開。
すべて相対パスなので `/<repo>/` のサブパスでも動きます。

## 2. iPad にインストール
Safari で開く → 共有 → 「ホーム画面に追加」。iOS 16.4+ ではインストール後の PWA のみ Web Push が使えます。
起動後、設定（歯車）から通知を許可してください。

## 3. FCM（即時プッシュ）を有効にする
GitHub Pages は静的ホスティングのため、FCM の送信側は `relay/` を別途常時稼働させます。
1. Firebase プロジェクト作成 → Web アプリ追加 → `firebaseConfig` を `config.js` の `firebase` に、Cloud Messaging の「ウェブプッシュ証明書」公開鍵を `vapidKey` に設定。
2. サービスアカウント鍵（JSON）を発行。
3. `relay/` を Render / Fly.io / Railway / VPS 等へデプロイ（WebSocket 常時接続のため、スリープしない構成で）。
   - `FIREBASE_SERVICE_ACCOUNT` = JSON 文字列
   - `ALLOWED_ORIGIN` = `https://<user>.github.io`
4. 公開URLを `config.js` の `relayUrl` に設定。
5. アプリの設定で「プッシュ通知（FCM）」をオン。

端末は次のトピックに登録されます（中継サーバー v2）。
- `quake-alert` … 全端末。津波・緊急地震速報（地域別通知だけの端末にも届く）
- `quake-min-{10,30,40,45,55}` … 全国の最小震度
- `quake-pref-{1..47}-{10,30,40,45,55}` … 都道府県別の最小震度

同じ地震の続報では、新たにしきい値を超えた端末にだけ通知音つきで送り、震源名が判明したときは無音で内容を更新します。緊急地震速報は第1報のみ通知します。
`relay/` を更新したら必ず再デプロイしてください（`logic.js` も含める）。`npm test` で通知ロジックのテストを実行できます。
環境変数 `KEEPALIVE_URL`（Render は `RENDER_EXTERNAL_URL` 自動）で10分ごとに自分の `/healthz` を呼びスリープを防ぎます。外部の死活監視（UptimeRobot 等）の併用がより確実です。

## 主な機能（v2.1）
- **リアルタイム監視モニタ**（ヘッダーの脈拍アイコン）: P2P 地震感知情報(561)を地図上にリアルタイム表示（直近1分の件数で色・大きさが変化、新着は波紋）。感知数の10分推移グラフ、感知急増の検知、緊急地震速報のP波・S波の同心円、直近の地震、受信ログ、接続状態を1画面に集約。
- **接続診断**（設定 › 診断・ツール）: 起動方法・通知許可・Service Worker・プッシュ登録・中継サーバー・P2P API・WebSocket を一括チェックし、通知が届かない原因を特定。
- **防災訓練**（同上）: 緊急地震速報の全画面警報・音声・カウントダウンを実際の警報と同じ流れで体験（【訓練】表示、通知は送信されません）。
- **履歴のCSV保存**（同上）。
- 設定・統計・モニタを開いている間に警報が来ても、ダイアログを閉じて警報を最前面に表示します。トーストもダイアログの上に出ます。
- モニタの感知データは「アプリを開いている間に受信した分」のみです（強震モニタ（防災科研）の観測波形ではありません）。

## 主な機能（v2.5）
- **タイムライン**（ホーム）: 地震・津波・噴火・緊急地震速報を1本の時系列で表示。タップで詳細やタブへ移動。
- **余震・関連地震**（地震の詳細）: 同じ震源域（M5未満は半径50km、M5以上90km、M6以上150km）の、前24時間と以降7日間の地震を、読み込み済みの履歴から集計して表示。
- **揺れた！ 行動ガイド**（ホーム / 備え）: 経過タイマー、津波・直近の地震・余震の状況、順に確認するチェックリスト、避難所の地図検索。緊急地震速報などの警報が出ると自動で閉じて警報を優先。
- **震度の目安**と**避難所を地図で探す**リンク（備え）。
- **画像で共有**（地震の詳細）: NERV 風のカード画像（震度・震源・M・深さ・あなたの地域の震度）を作成して共有/保存。

## 主な機能（v2.4）
- **ホーム**（左ペインの最初のタブ）: 平常 / 注意 / 警戒の状態表示、現在地、最新の地震、見守り地点、24時間と7日間の傾向、最近の緊急地震速報。
- **緊急地震速報の「現在地予想震度」**: 登録した現在地の都道府県の予想震度（例: 4〜5弱）を、S波到達カウントダウンと並べて表示（警報バナー・全画面警報とも）。都道府県単位の目安で、地点ごとの正確な予測ではありません。
- **見守り地点**（設定）: 実家など最大4つの都道府県を登録し、直近24時間の揺れと緊急地震速報の予想震度をホームに表示。
- **ティッカー**: 状態・最新の地震・津波・噴火を流れる帯で常時表示。ヘッダーに日本時間の時計。
- 一覧に震度色のストライプ、詳細に震度別の観測点数グラフ。

## 主な機能（v2.3）
- **情報タブ（左ペイン）**: 地震 / 津波 / 噴火 / 備え。津波は発表中の地域別の到達時刻・予想高さと過去の発表、噴火は気象庁の噴火速報・噴火警報・降灰予報など。発表中は赤い点を表示。
- **引っ張って更新**: 一覧・津波・噴火タブの先頭から下に引っ張ると更新。
- **噴火速報・噴火警報のプッシュ通知**（設定でオン/オフ）。中継サーバーが気象庁の防災情報XMLフィードを1分ごとに確認します（フォーマットは気象庁の仕様に依存。取得できない場合は表示のみ縮退）。
- **配信経路テスト**（設定）: 実際の地震通知と同じ経路（サーバー→トピック→端末）での確認。
- **接続診断の強化**: 中継サーバーの版・直近の受信/送信・スリープの疑い・噴火フィードの状態を表示。
- 中継サーバーは、スリープ復帰・再起動直後に直近8分の取りこぼしを補完して通知します（「受信が遅れました」と付記）。
- **無料プランのスリープ対策**: UptimeRobot 等で `https://<サーバー>/healthz` を5分ごとに監視してください（アプリを開くたびにも起こしますが、閉じている間は外部監視が必要です）。

## 補足
- Leaflet は unpkg（v1.9.4 固定）から読み込み、初回アクセス後は SW がキャッシュします。自己完結にしたい場合は `vendor/` に置き、`index.html` と `sw.js` のURLを差し替えてください。
- 地図は国土地理院タイル（淡色地図）をCSSで暗色化しています。出典表示は地図右下に出ます。
- `sw.js` を変更したら `VER` を上げるとキャッシュが更新されます。
